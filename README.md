# 🏛️ ТАЙНА ЯНТАРНОЙ КОМНАТЫ — Telegram-бот

Интерактивная историческая игра-детектив. 12 сцен, 5 концовок, 3 квиза.

---

## Быстрый старт

### 1. Создать бота

Откройте [@BotFather](https://t.me/BotFather) в Telegram:
```
/newbot
```
Назовите бота, например: `AmberRoomBot` / `@ваш_бот`
Скопируйте токен.

### 2. Установить зависимости

```bash
pip install python-telegram-bot==20.7
```

### 3. Запустить

```bash
BOT_TOKEN=ваш_токен_здесь python bot.py
```

Или добавьте токен прямо в переменную окружения:

**macOS/Linux:**
```bash
export BOT_TOKEN=ваш_токен
python bot.py
```

**Windows (cmd):**
```cmd
set BOT_TOKEN=ваш_токен
python bot.py
```

## Структура игры

```
/start
  └── Пролог (фото Янтарной комнаты)
       └── Квиз К1: История комнаты (3 вопроса × 10 очков)
            └── Развилка Р1
                 ├── Путь А: Допросы
                 │    ├── А1: Досье Роде
                 │    ├── А2: Допрос Роде (2 сюжетных выбора × 5 очков)
                 │    ├── Квиз К2: Кёнигсберг (3 вопроса × 10 очков)
                 │    └── А3: Письмо Роде (1 сюжетный выбор × 5 очков)
                 └── Путь Б: Документы
                      ├── Б1: Архив замка
                      ├── Б2: Личная запись (1 сюжетный выбор × 5 очков)
                      ├── Квиз К3: Персонажи (3 вопроса × 10 очков)
                      └── Б3: Допрос Фейерабенда
                           └── Главная развилка Р2 (5 концовок)
                                └── Квиз К4: Финал (3 вопроса × 10 очков)
                                     └── Итоговый экран
```

### Очки
| Элемент | Очки |
|---------|------|
| Правильный ответ в квизе | +10 |
| Верный сюжетный выбор | +5 |
| **Максимум** | **55** |

### Звания
| Очки | Звание |
|------|--------|
| 0–20 | 🔍 Начинающий следователь |
| 21–40 | 🕵️ Опытный детектив |
| 41–55 | ⭐ Мастер расследования |

## Деплой (постоянная работа)

### Вариант А: Render.com (бесплатно)

1. Залейте код на GitHub
2. Создайте новый **Web Service** на render.com
3. Укажите: `pip install python-telegram-bot==20.7 && python bot.py`
4. В Environment Variables добавьте `BOT_TOKEN`

### Вариант Б: Railway.app

1. Создайте проект, подключите GitHub
2. Добавьте переменную `BOT_TOKEN`
3. Деплой автоматический

### Вариант В: VPS (systemd)

```ini
# /etc/systemd/system/amberbot.service
[Unit]
Description=Amber Room Bot

[Service]
ExecStart=/usr/bin/python3 /opt/amberbot/bot.py
Environment=BOT_TOKEN=ваш_токен
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable amberbot && systemctl start amberbot
```

## Расширение

Чтобы добавить новые сцены:
1. Добавьте новую функцию `scene_*`
2. Зарегистрируйте её в словаре `routes` в `button_handler`
3. Добавьте `callback_data` кнопку в нужной сцене
