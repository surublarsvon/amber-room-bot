# 🏛️ Тайна Янтарной комнаты

Интерактивная историческая игра-детектив в формате Telegram-бота.

---

## О проекте

Этот бот — учебный проект по истории, созданный как ответ на простой вопрос: почему молодые люди не интересуются историей?

Традиционные форматы — учебники, лекции, статьи — плохо работают в эпоху клипового мышления. При этом проблема глубже, чем просто «неинтересно»: современный человек привык получать готовые ответы и доверять единственной «официальной» версии событий, не задумываясь об альтернативах.

История исчезновения Янтарной комнаты — идеальный случай для другого подхода. Здесь нет одного правильного ответа. Есть противоречивые свидетельства, засекреченные архивы, подозрительные смерти и пять версий, каждая из которых подкреплена реальными документами. Именно это делает её материалом для детектива, а не учебного параграфа.

**Цель:** создать игру, в которой игрок не читает про историю, а сам ведёт расследование — изучает улики, допрашивает свидетелей, оценивает версии и делает выбор.

---

## Что внутри

```
12 сцен  ·  2 пути расследования  ·  5 концовок  ·  3 квиза  ·  90 очков максимум
```

**Два пути расследования:**
- **Путь А** — начать с допросов: Альфред Роде, показания Фейерабенда
- **Путь Б** — начать с документов: архив замка, личные записи, приказы Бормана

**Пять версий исчезновения** (все основаны на реальных исторических данных):
- 🏰 Подземные бункеры Кёнигсберга
- ⛏ Соляные шахты Тюрингии
- 🌊 Пароход «Карлсруэ» на дне Балтики
- 🤝 Передана США в счёт долгов по ленд-лизу (версия Мосякина)
- 🔥 Уничтожена в пожаре (версия Роде — опровергнута)

**Система очков:** только за правильные ответы в квизах (+10 за вопрос). Повторные нажатия не дают очков. При повторном прохождении счёт обнуляется.

## Что было сделано

1. Изучены основные источники: Мосякин А.Г., Воронов М.Г., Кучумов А.М., Овсянов А.П., материалы РИА Новости и рассекреченные архивы ФСБ (2025)
2. Составлена хронология событий, прописаны персонажи и пять версий исчезновения
3. Написан полный сценарий с развилками, квизами и концовками
4. Создан Telegram-бот с системой очков, изображениями и списком источников

**Что не удалось реализовать:**
- Более детальная проработка второстепенных версий, персонажей и локаций
- Перенос в более стабильную платформу (Railway периодически требует внимания)

## Установка и запуск

### Требования
- Python 3.11
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)

### Локально

```bash
git clone https://github.com/ваш-username/amber-room-bot
cd amber-room-bot
pip install -r requirements.txt
BOT_TOKEN=ваш_токен python bot.py
```

### Railway (рекомендуется)

1. Форкните репозиторий на GitHub
2. Зайдите на [railway.app](https://railway.app) → New Project → Deploy from GitHub
3. В разделе Variables добавьте: `BOT_TOKEN` = ваш токен
4. Railway запустит бота автоматически
